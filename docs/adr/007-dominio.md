# ADR-007 — Domínio único vettafit.com.br

**Status:** aceito (decisão do produto)

- `vettafit.com.br`: landing e páginas de venda (`/p/[slug]`)
- `app.vettafit.com.br`: web do personal e do aluno
- `admin.vettafit.com.br`: painel da plataforma
- `api.vettafit.com.br`: API
- `cdn.vettafit.com.br`: mídia

O app mobile usa o scheme `vetta://` e universal links em `app.vettafit.com.br`.
